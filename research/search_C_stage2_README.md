切换负责“保住 B 的 2024（全年持 B）+ 吃到 A 的 2025/2026”（#1：2023-08-18 切 B 后 2024 全年持 B，2025-03-19 切 A，2026-05-18 回 A）；
刹车（自身权益回撤 bx 触发、新开仓降至 bf、反弹 by 解除）把 B 腿 2024 年内约 -32.6% 的坑削到约 -17%，是过线的关键。
grid 下 mh0/mh10 同解（切换间隔本就数月，min_hold 不绑定）；daily+hyst 用迟滞带/确认数减少鞭打。
