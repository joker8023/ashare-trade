# A股尾盘六步选股

把"涨幅3-5% → 涨停记忆 → 小市值 → 放量 → 换手率 → 分时形态"的六步人工选股流程，做成可复现的量化漏斗。

**核心原则：宁可给出 0 只，也不要凑名单。** 六条是全中制，不是加权打分；凑数出来的票比空仓伤害更大。

## 什么时候用

- 交易日的 14:30 之后（尾盘确认窗口），或收盘后复盘当日尾盘形态
- 用户要求按这套规则选股、或问"今天有什么票符合"
- 用户想改参数（比如今天这种极端行情要放宽涨幅区间）

## 先跑环境体检，再谈选股

选股前必须先看清今天的市场结构，否则容易在错误的前提下给出"合规但无意义"的名单：

```bash
node .dsh/skills/ashare-six-step-screen/scripts/screen.mjs --breadth
```

输出里包含指数涨跌与全市场涨跌分布。判读规则：

| 市场状态 | 判据 | 对这套策略的影响 |
|---|---|---|
| 常态 | 指数涨跌在 ±2% 内 | 3-5% 区间是"启动初期"，策略原意成立 |
| 普涨/极端 | 某指数涨 > 5%，或涨幅 > 5% 的股票占比超过 60% | **3-5% 变成全市场滞涨股**，第 6 条几乎必然不过，必须提示用户 |
| 普跌 | 指数跌 > 2% | 3-5% 是逆势强势股，稀缺但可信度反而高 |

遇到极端行情，先向用户说明"目标区间与当日结构错配"，再给出建议区间（通常是当日中位涨幅附近），不要默默放宽。

## 执行

```bash
# 默认：涨幅3-5%、市值<200亿、量比>1、换手5-10%、近4日有涨停
node .dsh/skills/ashare-six-step-screen/scripts/screen.mjs

# 加市场宽度 + 一键给前 2 只画分时图
node .dsh/skills/ashare-six-step-screen/scripts/screen.mjs --breadth --charts 2

# 极端行情放宽（示例：涨幅 5-8%）
node .dsh/skills/ashare-six-step-screen/scripts/screen.mjs --pct 5 8 --breadth

# 收紧或改窗口
node .dsh/skills/ashare-six-step-screen/scripts/screen.mjs --pct 3 5 --cap 100 --turn 8 12 --days 3
```

参数：`--pct 低 高` `--cap 亿` `--vr 量比下限` `--turn 低 高` `--days 涨停记忆回看天数` `--charts N` `--breadth` `--out 路径`。

产物：

- `results/screen_<北京日期_时分>.json` — 全部候选的原始指标与判定
- `results/min/<代码>.json` — 分时序列，供画图
- 控制台：漏斗计数 + 逐只失败原因

画分时图：

```bash
.venv/bin/python .dsh/skills/ashare-six-step-screen/scripts/render_fenshi.py results/min/002566.json results/min/600488.json
```

依赖：Node 18+（内置 fetch）、Python 里的 matplotlib（本项目 `.venv` 已装）。

## 结果怎么读

脚本给出 A / B / C 三级，**只有 A 是六条全中**：

- **A 级**：三信号全成立，可作为候选
- **B 级**：仅一条不过且属"近失"（跌破均价线只在 10:00 前 / 尾盘距日高 ≤1% / 回踩踩线 ≤0.3%），提示用户"差一口气"，由用户决定是否接受
- **C 级**：两条以上不过，只作为反面对照，不进推荐

报告里每只票必须写清楚**哪一条不过、差多少**，例如：

> ✗ ② 日高 20.10@13:50，14:30 后最高 19.92@14:53，差 -0.90%

## 第⑥步的严格定义（最容易做错的地方）

1. **全天在均价线之上**：按分钟收盘价对比均价线（VWAP），0 根在下方才算成立。要同时报出"线下占比 / 最深幅度 / 最后一次跌破时间 / 午后根数"——只在开盘 30 分钟内跌破的，属于可讨论的"近失"。
2. **14:30 后创当天新高**：用**分钟最高价**（不是收盘价）比较 14:30 前后，尾盘最高 > 14:30 前最高。仅持平日高不算突破，要明说"仅回抽未突破"。
3. **新高后回踩不破均价线**：取尾盘最高点之后的分钟**最低价**，与对应时刻的均价线比较，不得低于；同时要求回踩幅度 ≥0.15% 且后续至少 3 根，避免把"最后一根创新高"误判为"回踩守线"。

第 2 条不成立时，第 3 条不评估（不产生"无回踩"的伪失败）。

## 报告模板

```
## 结论
严格六条：A 级 N 只；B 级（近失）M 只。

## 市场环境
指数：… ；全市场涨幅>5% 占比 …%
（若极端，说明目标区间含义已改变）

## 漏斗
抓取样本 → ① → 剔ST → ③ → ④ → ⑤ → ② → ⑥

## 名单
| 代码 | 名称 | 涨幅 | 换手 | 量比 | 市值 | 涨停记忆 | 判定 |
（A/B/C 分级，B/C 写明差在哪）

## 分时图
（A、B 级的图）

## 风险提示
不构成投资建议…
```

## 硬性要求

- 每个结论都带**时间戳**（数据是 14:35 的还是收盘的，必须写清楚）
- 14:30 前跑出的换手率、量比是盘中值，口径偏小，脚本会告警，报告里也要说明
- 不做"次日必涨"之类的断言；形态只是概率，不给目标价、不给仓位建议
- 结尾固定加风险提示

## 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| ①涨幅区间 0 只 | 分页被截断（旧脚本按 30 页封顶） | 本脚本自动翻到涨幅跌破下沿，最多 90 页 |
| 报 `fetch failed / SocketError` | 东财限流 | 脚本自带 6 次退避重试；仍失败时隔几分钟再跑 |
| ⑥全部为 0，但形态看着不错 | 第 2 条用了收盘价或时间字符串比较错误 | 确认用分钟最高价，且时间先 `slice(11,16)` 再比 `"14:30"` |
| 涨停记忆漏掉明显涨停股 | 未按板块区分涨停幅度 | 主板10%、创业板/科创板20%、北交所30%、主板ST 5% |
| 市值口径对不上 | 总市值 f20 / 流通市值 f21 混用 | 统一用总市值 `f20`，报告里注明 |

更细的字段口径见 [references/data-sources.md](references/data-sources.md)，规则与阈值推导见 [references/methodology.md](references/methodology.md)。
