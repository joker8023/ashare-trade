# 数据源与字段口径

全部数据来自东方财富的公开行情接口（免费、无需登录、实时）。请求需带 `User-Agent` 与 `Referer`，否则可能被拒。

## 1. 全市场快照

```
https://push2.eastmoney.com/api/qt/clist/get
  ?pn=1&pz=100&po=1&np=1&fltt=2&invt=2&fid=f3
  &fs=m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23,m:0+t:81+s:2048
  &fields=f2,f3,f8,f10,f12,f14,f20,f21,f62,f100
```

| 参数 | 含义 |
|---|---|
| `fid=f3&po=1` | 按涨跌幅降序 |
| `pz` | 每页条数，**实际被限制在 100** |
| `fs` | 市场范围：沪主板 + 深主板 + 创业板 + 科创板 + 北交所 |

| 字段 | 含义 | 单位 |
|---|---|---|
| f2 | 最新价 | 元 |
| f3 | 涨跌幅 | % |
| f8 | 换手率 | % |
| f10 | 量比 | 倍 |
| f12 / f14 | 代码 / 名称 | — |
| f20 / f21 | 总市值 / 流通市值 | 元 |
| f62 | 主力净流入 | 元 |
| f100 | 所属行业 | — |

**坑 1：分页会被静默截断。** 涨跌幅降序排列时，3-5% 区间常常落在第 40-50 页；早期版本按 30 页封顶，导致区间内 0 只。正确做法是翻页直到某页最小涨幅跌破 `区间下沿 - 0.6`，最多 90 页。

**坑 2：盘中排序会漂移。** 股票涨跌实时变化，翻页期间会重复返回同一只股票。必须按 `f12` 去重。

**坑 3：连接被重置。** 东财会突发 `SocketError: other side closed`。需要 6 次退避重试；单页失败可跳过，但连续 3 页失败应当中止而不是返回残缺结果。

## 2. 日线（有色复盘 / 涨停记忆）

```
https://push2his.eastmoney.com/api/qt/stock/kline/get
  ?secid=0.000593&klt=101&fqt=0&end=20500101&lmt=12
  &fields1=f1,f2,f3,f4,f5,f6
  &fields2=f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61
```

- `secid` = `1.` + 代码（沪市 6/9/688 开头）或 `0.` + 代码（深市、北交所）
- `klt=101` 日线；`fqt=0` 不复权
- `fields2` 顺序固定：日期, 开盘, 收盘, 最高, 最低, 成交量, 成交额, 振幅, 涨跌幅, 涨跌额, 换手率

返回的 `klines` 是逗号分隔字符串数组，**最后一根是当天（盘中为未完成状态）**。算涨停记忆时必须排除它。

## 3. 分时（第 6 步）

```
https://push2his.eastmoney.com/api/qt/stock/trends2/get
  ?secid=0.000593
  &fields1=f1,f2,f3,f4,f5,f6,f7,f8,f9,f10,f11,f12,f13
  &fields2=f51,f52,f53,f54,f55,f56,f57,f58
  &iscr=0&ndays=1
```

`data.trends` 每行：`时间,开,收,高,低,成交量,成交额,均价`

| 下标 | 含义 |
|---|---|
| p[0] | `"2026-11-27 14:31"` 完整时间字符串 |
| p[2] | 该分钟收盘价（画线用这个） |
| p[3] / p[4] | 该分钟最高 / 最低（判断"创新高""跌破"必须用） |
| p[5] / p[6] | 成交量（手）/ 成交额（元） |
| p[7] | **均价线 VWAP** |

**坑 4：时间字符串不能直接和 "14:30" 比。** `"2026-11-27 14:31" >= "14:30"` 永远为真（首字符是 2 > 1），会让"尾盘创新高"全部误判为成立。必须先 `t.slice(11, 16)` 取出 `"14:31"` 再比较。

**坑 5：均价线字段需要验证。** 抽查一根：`成交额 ÷ (成交量 × 100)` 应等于 `p[7]`。若不一致，说明字段位置变了，先修正再跑。

`data.preClose` 是昨收，可用来算当日涨幅、渲染昨收参考线。

## 4. 指数（市场环境）

```
https://push2.eastmoney.com/api/qt/stock/get?secid=1.000001&fields=f43,f60,f170
```

- `f43` = 最新点位（×100）、`f60` = 昨收（×100）、`f170` = 涨跌幅（×100）
- 常用 secid：上证 `1.000001`、深成指 `0.399001`、创业板指 `0.399006`、科创50 `1.000688`、北证50 `0.899050`

## 5. 涨跌分布

复用快照接口，只取 `f3,f12`，按阈值分箱统计。全市场约 5000-5900 只，翻完约 40-60 页，建议每页间隔 100ms 避免限流。

## 6. 同花顺页面为什么不能直接用

用户常见的入口是 `data.10jqka.com.cn/rank/cxg/`（技术选股 → 创新高）。它有两个限制：

1. **盘后更新**：页面顶部"更新时间"通常停在前一交易日，不是实时
2. **样本受限**：只列出创新高个股，不含全市场，无法做"3-5% 区间"这类横截面筛选

它适合做"创新高"名单的交叉验证，不适合作为筛选数据源。需要实时全市场时用上面的东财接口。
