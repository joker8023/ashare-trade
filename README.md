# A股 Amihud 流动性因子策略

> 从零开始的 A股量化因子研究，最终产出一个经过滚动样本外验证、可落地的流动性溢价策略。
>
> 数据: AKShare 前复权日线 · 5028 只沪深A股 · 2010-01-04 ~ 2026-11-04

---

## 一、策略规格

```
选股:  全A沪深, 剔除 ST / 上市不足250日 / 日均成交额<500万
       流通市值取 5%~30% 分位 (小微盘)
       按 Amihud 非流动性 = mean(|日收益| / 成交额(亿)) 排序
       取最高的 50 只, 等权
调仓:  每 60 个交易日
风控:  中证1000 收盘 < MA20 → 仓位降至 50%
成本:  单边 0.5% (佣金+印花税+滑点)
```

**因子逻辑**: Amihud 非流动性衡量「单位成交额能推动多少价格」。流动性越差的股票，
投资者要求的补偿越高，形成流动性溢价。A股散户占比高、小微盘关注度低，这个溢价尤其明显。

## 二、预期表现

| 场景 | 年化 | 夏普 | 最大回撤 |
|---|---|---|---|
| 全样本 2011-2026 | 37.0% | 1.23 | -42.8% |
| **滚动样本外** | **37.6%** | **1.28** | -41.6% |
| **剔除 2013-15 小盘泡沫** | **21.4%** | 0.86 | — |
| 1000万资金实盘估算 | ~33% | 1.14 | -43% |

> 合理预期是 18-22% 年化。37% 那个数字被 2013-2015 小盘泡沫抬高了。
> 剔除后 21.4% 才是这个策略的"正常年份"水平。

### 必须接受的代价

- **最大回撤 -42%**，2015 股灾 76 天腰斩
- **2017、2018 连续两年亏钱** (-10.8% / -22.2%)
- **最长 3.2 年不赚钱** (2017-04 到 2020-07)
- **容量上限 1 亿**，超过就废

## 五、验证证据

### 1. 十分层单调性 (2011-2026)

```
层1(最流动)  -7%   层2  -4%   层3  -1%   层4  +0%   层5  +2%
层6         +5%   层7  +8%   层8 +13%   层9 +16%   层10 +44%
```

单调递增 9/9，层序与收益相关系数 **0.871**，多空年化 +50.7%。

### 2. 滚动样本外 (每年只用历史数据选参数)

| 年份 | 当年收益 | 夏普 |
|---|---|---|
| 2015 | +263.4% | 2.84 |
| 2017 | -7.4% | -0.45 |
| 2018 | -25.6% | -1.19 |
| 2021 | +31.4% | 2.10 |
| 2025 | +67.3% | 3.11 |
| 2026 | +21.0% | 1.17 |

**年化 37.6%，夏普 1.28，12/14 盈利年，14/14 次主动选中风控。**

### 3. 资金容量 (平方根冲击模型)

| 资金 | 年化 | 夏普 |
|---|---|---|
| 100万 | 37.2% | 1.01 |
| 1000万 | 31.8% | 0.90 |
| 5000万 | 22.5% | 0.71 |
| 1亿 | 15.9% | 0.57 |
| 3亿 | 0.5% | 0.23 |

## 六、已证伪的方向 (不要重复试)

- 动量因子 — IC 显著为负 (-0.047)，A股动量完全失效
- 复合因子 — IC 从 0.045 升到 0.072，但年化从 38% 掉到 28%
- 个股止损 — 所有档位降夏普，小盘股均值回复太快，止损=卖在最低点
- 波动率目标 — 年化 30%→13%，因为高波动期往往是反弹起点
- 波动率加权 — 降收益
- 行业中性化单独使用 — 只提升 ICIR，叠加择时才有价值
- 行业集中度风险 — 本来就很分散 (52个行业，有效行业数 24.5)

## 七、已知局限

| 局限 | 影响 |
|---|---|
| **幸存者偏差** | 股票池仅为当前上市股票，退市股未纳入 → 收益虚高 |
| **样本期短** | 实际回测仅 2011-2026，未覆盖 2008 金融危机 |
| **容量限制** | 小微盘流动性差，1亿以上失效 |
| **数据来源** | AKShare 免费源，可能有缺失或错误 |
| **无实盘验证** | 滑点用平方根模型估算，未经真实成交检验 |
