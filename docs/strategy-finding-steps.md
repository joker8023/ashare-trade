## 0. 先定位：你是谁、玩什么局

不定位，后面全白搭。见 refer E13、E20。

开工前先回答三问，写进每次研究的开头（README / 台账第一行）：

1. 钱：多大资金、能扛多大回撤？（按回撤倒推仓位，不要按收益倒推梦想）
2. 时间：每天能看几分钟？不能盯盘就别碰日内/集合竞价博弈。
3. 信仰：策略连亏 2 年、回撤 40% 时你砍不砍？砍不动的，参数再好也不能上。

选赛道对照（E03 三笔账：能赚多少 / 能亏多少 / 凭什么你赚）：

| 策略族 | A股散户能不能碰 | 本仓库实测结论 |
|---|---|---|
| 小微盘流动性/低换手因子＋季调仓 | 首选 | Amihud 年化 31.3% / 回撤 -23% / 夏普 1.39（现实成本 0.5%），唯一过滚动样本外的 |
| 低波动回撤 / 固定幅度回调（价位限价单） | 有条件 | 0.15% 成本下 +29~32% 很美，0.5% 现实成本下只剩 +3~7%，成本直接杀死 |
| 趋势跟踪（唐奇安突破/金叉死叉追突破） | 别碰 | 21 组全灭：最好 -5.1%，最差 -31%，唐奇安 -17~-24%（见 FINAL_10 附录） |
| 事件驱动（财报/分红/并购） | 看信息 | 方差大，没信息优势别碰 |
| 高频/做市 | 划掉 | 不是不赚钱，是轮不到你（E03 原话）；A股还有 T+1＋涨跌停锁死 |
| 机器学习/AI | 只做增强 | 传统策略定方向、AI 提精度（E02）。先有逻辑因子＋基准跑赢，再谈模型 |

散户优势要用好：不用考核、小票猎场、仓位自由、不用跑赢指数。劣势要认：延迟、费率、信息、工具，全部用成本和规则补。

一句话：没有最好的策略，只有合脚的策略。选错路，努力十年白费。

## 2. 写假设：先写字，再看数据

回测只能验证，不能发现。顺序反了跑多少遍白费。见 refer E04。

每个新策略必须有一句话假设＋否证条件，写进脚本头部 / 台账：

- 赚什么钱？（例：小微盘流动性差→投资者要求补偿→流动性溢价；低波动股的超跌更容易均值回复）
- 什么行情赚？什么行情会亏？（牛/熊/震荡/暴跌各一句。例：2017/2018 大盘价值风格时本策略连续两年亏钱）
- 什么情况下算错了、必须放弃？（否证线，不是止损线。例：十分层单调性消失、IC 转负连续 2 年）

假设台账建议：观察 → 假设 → 逻辑 → 验证方案 → 否证条件。来源只有四处：市场异象、行为偏差、学术/经典策略、生活观察。

## 3. 翻译成可执行的五零件

低估值就买是心情，不是策略。见 refer E05、E14。

五个零件缺一个不开工（A股版）：

1. 选股：股票池＋过滤（例：全A沪深，剔除 ST / 上市<250天 / 日均成交额<500万；流通市值 5%~30% 分位；按 Amihud 取前 50 只等权）
2. 买入：精确触发（例：昨收减 0.3×ATR14 挂限价单；或每 60 交易日调仓日按收盘/次日开盘调）
3. 卖出：止盈 / 时间止损二选一必须有（例：买入价加 0.8×ATR14 止盈；或最长持有 20 天强制平仓；因子策略为调仓日轮换）
4. 仓位：固定分数（例：每只 5%、最多 20 只；或指数破位降至 50%/清仓）
5. 止损：A股特别注意——本仓库 10 个价位策略里 9 个加止损降夏普（均线回踩 1.20→0.40）。小盘超跌股止损等于卖在最低点。如坚持要，加在 -15% 以外并接受收益下降。系统性风险靠大盘择时，不靠个股止损。

落地六步（E14 原顺序，不许反）：

一句话写出策略 → 回答五问（买什么/什么价买/什么条件卖/买多少/亏多少走）→ 把形容词翻成参数 → 写中文伪代码 → 每个零件单测 → 拼起来跑回测

提醒：简单优于复杂。因子比参数重要（好因子＋烂参数能活，烂因子＋神参数必死）；因子会失效，要定期体检。8 个参数就是把墙拆了（E10）。

## 5. 评价标尺：先算期望，再看曲线

见 refer E01、E11。

- 期望值才是结果指标：期望 = 胜率×均盈 - 败率×均亏。70% 胜率也能靠盈亏比 0.68 赚钱（本仓库方案 A：胜率 70.2%、盈亏比 0.68），60% 胜率配大亏一样亏光。不要只看胜率。
- 方差杀心态：60% 胜率跑 200 笔，87% 会撞上连亏 5 次。连亏先查执行和环境，再怀疑策略。
- 下注比例：凯利算出来再打对折（半凯利）；2015 千股跌停、2024 微盘闪崩那种时刻，仓位就是命。
- 回测四指标及格线：年化 / 最大回撤 / 夏普 / 期望值综合看。夏普>2 先怀疑是不是靠 1–2 笔极端交易；去掉最赚的 1–2 笔还赚钱吗？本仓库 Calmar≈夏普，要 10% 回撤年化上限约 15%，要 40% 年化回撤至少 25%，两者不可兼得（见 FINAL_10）。
- 时间序列要平稳假设：趋势/季节/自相关会变，真市场不平稳。2013–15 小盘泡沫把 37% 抬高了 15pp，剔除后 21.4% 才是正常水平——样本外不行就是不行。

## 6. 相关性＋宏观：方向错了，选股再准白搭

见 refer E21、E16。

- 20 只小盘看着分散，经常同涨同跌等于伪分散。算两两相关矩阵，大于 0.7 就是同一个赌注。本仓库天然分散（52 个行业、有效行业数 24.5），但仍需定期重算。
- 皮尔逊只认线性，极端值用斯皮尔曼；相关不等于因果，要找到驱动（流动性/小盘风格/市场情绪）。
- A股温度计（照搬 E16 思想）：GDP、CPI、M2、10 年国债、社融、PMI 各打 0–100 分加权；75 以上五成仓、60–75 七成、40–60 八成、25–40 五成、25 以下三成；再按温度切换成长/价值因子。本仓库简化版：中证1000/500 收盘小于 MA20 → 降仓/清仓（8–10pp 收益换 22–25pp 回撤改善，夏普反而上升）。
- 定期重算相关性，不要拿三个月前的分散当现在的分散。

## 7. 验证三关＋四坑排查（核心）

见 refer E10、E11、E12。

### 7.1 三关必须全过

第一关：参数敏感性（去孤峰）

- 每个参数正负 10–20% 扰动（20→18/22），看收益/夏普/回撤是连续丘陵还是断崖。
- 孤峰直接死刑；夏普>2 先怀疑；去掉最赚的 1–2 笔还赚钱吗？
- 本仓库案例：止盈 0.8/1.0/1.2 ATR 都能活（丘陵）→可信；单因子孤峰＋多参数硬凑→死刑。

第二关：时间切分（顺时间，只许往前）

- 训练（旧的，调参）→ 验证（中的，选型，不许反复回炉）→ 样本外（新的，只跑一次，跑完不许改参数）
- 错误示范：用 24–26 调参测 22–23；拿单月神准当证据。
- 覆盖两种市况以上：牛/熊/震荡/暴跌至少见过两种。本仓库要求至少扛过 2015 股灾＋2017–18 价值熊＋2024 微盘闪崩中的两段。
- 不行回第 2 节改逻辑，不许改数字。对应脚本：walkforward_v3.py（滚动样本外）、decile_test.py（十分层跨期稳定性）。

第三关：多品种/多指数铺开（同参数）

- 同一套参数跑多指数（中证500/1000/全A）、多因子组合、多调仓周期（20/60 日）。
- 通过标准：大方向一致、回撤可解释，不是每个格子都漂亮。
- 小盘/换周期崩了，给出市况解释；不许每个品种一套参数，不许加参数硬凑。
- 组合看分账：多头收益 / 择时贡献 / 成本侵蚀分开看，不能只看总曲线。

### 7.2 四坑＋八问（上线前排雷）

四坑（踩一个白干）：未来函数 / 忽略成本 / 过拟合 / 幸存者偏差。A股版：

- 未来函数：用当日收盘价当日建仓、停牌股按能成交算、财报/除权时点穿越
- 忽略成本：佣金＋印花税（卖出单边）＋滑点＋冲击成本。价位策略 0.15%→0.5% 年化掉 30pp（38%→7.6%），因子策略只掉 0.7pp——频率越高死得越惨
- 过拟合：324 选 1、8 参数墙、单月单因子神准
- 幸存者偏差：本仓库股票池仅为当前上市公司，退市股未纳入→收益虚高，真实收益打 8 折看；且未覆盖 2008 金融危机

回测目的是排雷，不是证明你对。上线前八问：逻辑自洽？成本按实盘（0.5%）？无未来函数？样本外过了？多指数可解释？极端行情见过（2015/2018/2024）？心理扛得住（最大回撤×1.5）？不加参数也能讲通？

### 7.3 越调越差先诊断（E12）

回撤先分三类：正常波动（历史最大回撤内）→等；退化（逻辑还在、收益衰）→降仓观察；失效（前提被结构推翻：如小盘风格系统性切换、印花税/融券规则大改、策略拥挤）→重构。

四原因：用搜索代替假设、跳过归因直接干预收益、目标只有收益、没有记录。五步调参：切数据→定范围步长→网格→筛候选→样本外验候选。七步重构＋版本管理（策略名＋大版本.小版本＋日期日志），没有回滚的调参等于裸奔。

## 8. 执行规则：A股先懂撮合，再谈成交

见 refer E23、E06。

- A股是价格优先＋时间优先＋集合竞价（9:15–9:25，9:20 后不可撤）＋连续竞价＋涨跌停（主板 10%、创业板/科创 20%、ST 5%）＋T+1。当日买入当日卖不掉，涨跌停封死根本成交不了。
- 本仓库成交模型：限价单，买入价小于等于当日最低价即成交；卖出/止盈建仓时锁定；最长持有 20 天强制平仓。这个假设偏乐观，实盘滑点只会更高——小盘股冲击成本用平方根模型估，1 亿以上策略失效。
- 四张收费单 A股版：滑点（小盘是大盘 4 倍）、手续费（佣金＋印花税，频率越高越贵）、流动性（极端时根本卖不掉）、延迟（低频可忽略）＋冲击成本。
- 动作：5 分钟自己算账（单边 0.5% 起步：佣金万2.5＋印花税千1＋滑点/冲击）→ 上实盘前十道闸门（成本/精度/余额/断线/重连/集合竞价/涨跌停/T+1/日志/kill switch）→ 先跑最小框架（小资金＋半仓＋手动确认）。

## 9. 上线后：盯三样＋三道防线＋管住手

见 refer E17、E18、E15、E19。

每天盯三层（10 分钟检查单，daily_signal.py 跑完顺手看）：

- 策略层：收益偏离、持仓集中度、信号频率（突然 3 倍要查）；择时状态（中证在 MA 上方还是下方）
- 系统层：数据更新是否成功、脚本报错、持仓文件是否写入
- 数据层：K 线延迟/缺失、异常值、除权除息是否对齐

阈值告警＋完整日志（策略/系统/数据分开记），先手动跑一段时间再自动化。三个血泪教训：节假日前忘看持仓、手痒改止损、忽略警告。

三道防线写进规则（A股没有 7×24，但有千股跌停）：

- 单日亏到 3% 当天收手（不加仓、不改单）
- 回撤 10% 砍一半（中证破位即半仓/清仓，不要等）
- 10–20% 应急池永远不动；熔断后用盈利分批回满仓，不要一次梭回；分散压注，单策略不超总资金 50%

管住手（技术三成、人七成）：

- 数据思维：写不出依据的不开；每笔留依据/计划/盈亏比/执行/复盘（交易日志）
- 纪律：止损/清仓交给条件单和指数规则，人只审核；每天三问反思纪律
- 概率：连亏 5 次是常态，先查执行和环境（E19：胜率 60%、200 笔里 87% 会撞上连亏 5 次）
- 无常：策略会失效，多策略组合＋每月体检，知道收手。每月自检清单打分，不及格回去练

情绪对策：贪恐指数＋换手率做情绪温度计、反向操作清单、只用条件单、少看盘、找到专属对抗机制（E15：处置效应赚了跑亏了扛、羊群效应追涨杀跌、过度自信频繁交易——量化就是用纪律对抗这三样）。

## 10. 版本＋复盘：没有记录等于没调过

- 版本号：策略名＋大版本（逻辑变）.小版本（参数变）＋日期；每次只动一个变量，留改动理由和回滚点。
- 每次研究必须留：假设（一句话）/ 参数表（数量＋理由）/ 敏感性结论 / 时间切分记录 / 指数矩阵结论 / 成本假设（0.15% 还是 0.5%）/ 否证线。
- 每月一次体检：因子还有效吗（IC/十分层）？相关性变了吗？温度/择时变了吗？拥挤了吗？容量还够吗？

流程一行：

定位 → 备数据 → 写假设 → 翻五零件 → 落码 → 算期望 → 查相关/温度 → 三关（敏感/时间/多指数）→ 排四坑 → 定执行成本 → 小仓上线 → 三层监控＋三道防线
