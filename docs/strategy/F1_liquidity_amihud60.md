# F1 流动性溢价（amihud_60）

> 一句话假设：越没人要的小微盘，流动性越差，投资者要求的补偿越高，持有它赚流动性溢价。
> 否证线：十分层单调性消失或IC转负连续2年即放弃。
> 数据声明：新浪前复权长历史（pivots_2020_clean.pkl，2010-01-04~2026-11-24，5030只，网格锚点2011-04-01）。旧 long 文件 TRAIN 63~81% 为接缝污染，已作废。

## 经济逻辑
- 赚什么钱：Amihud非流动性 = mean(|日收益|/成交额亿)，60日平滑版。流动性差→补偿高。
- 什么行情赚：小盘牛市（2024 +90.96%、2025 +72.31%）；什么行情亏：熊市温和段（2022 +5.85%、2023 +17.07%）。

## 五零件
1. 选股：上市>=250天、adv20>500万、流通市值5%~30%分位内再取窄盘0.02~0.15，按amihud_60取最高4只等权。
2. 买入：调仓日t信号，t+1收盘建仓。3. 卖出：每60交易日轮换，无个股止损。4. 仓位：中证1000收盘<MA15→20%，否则100%。5. 止损：不设。
