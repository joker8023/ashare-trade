口径（全部5个策略统一，引用数字时必须一起引用）：
- 数据：data/pivots_long_clean.pkl（2010-2026，前复权，5814只，含2020 TRAIN所需warmup），engine.py + risk_control.py
- 成本：单边0.5%（佣金+印花+滑点起步），t+1收盘建仓，等权，现金0收益
- 选股池：全A沪深，剔除上市<250日、日均成交额<500万（adv20>5e6）、当日收盘有效、流通市值截面分位过滤（见各策略size_range）
- 择时：中证1000（000852）收盘 < MA15 → 仓位20%（cut 0.2），否则100%。信号用昨日及以前数据（shift1），调仓日决策，无未来函数
- 区间：TRAIN 2020-01-01~2023-06-30（846天，含2020年完整），TEST 2023-07-01~2024-12-31（含2024-01微盘闪崩+04退市fear），OOS 2025-01-01~2026-11-12
- 幸存者偏差未修（仅当前上市公司，收益按×0.8折价看）；去头尾1-2笔检验缺失（engine无逐笔明细，已声明）；未建模涨跌停不可成交
- 复现例：ASHARE_PIVOTS=pivots_long_clean.pkl .venv/bin/python _final5_oos.py（或engine.py + risk_control.py按各策略参数）
