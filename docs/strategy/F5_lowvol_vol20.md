# F5 低波（vol20）

> 一句话假设：过去20天波动最小的窄盘票（没人炒的冷票），跌也跌不动，涨时跟涨，赚低波溢价+冷门补偿。
> 否证线：IC转负连续2年或高波牛市中持续跑输，即放弃。与F1同看冷门但不同维度：F1看额，F5看波。

## 经济逻辑
- 赚什么钱：f_vol20 = -std(日收益,20)，high端=波动最小。低波+小微重叠处是“没人看的票”，波动小、回撤小，择时后TEST 52%/-10%全场最稳。
- 什么行情赚：熊市+震荡（TEST）；什么行情亏：单边牛市中高波领涨时（TRAIN仅5%，2020-21高波牛）。
- 与F1区别：F1是额小，F5是波小；IC 0.061 vs 0.054同号但选股重叠低，是独立风险维度（低风险溢价）。

## 五零件
1. 选股：窄盘0.02~0.15，按vol20取最高4只（最低波4只）等权。
2. 买入：t+1收盘。
3. 卖出：每60日轮换，无止损。
4. 仓位：统一MA15_0.2。
5. 止损：不设。

## 参数表
- vol20-high N4 R60 0.02~0.15 cost0.5% MA15_0.2
