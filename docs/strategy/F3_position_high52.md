# F3 超跌位置（high52远端）

> 一句话假设：离52周高点最远的票（跌得最惨），超跌后容易均值回复，赚位置超跌，不是赚流动性。
> 否证线：IC转正（动量复活）连续2年或OOS转负，即放弃。A股动量已证伪（mom60 IC-0.047），本策略是反动量。

## 经济逻辑
- 赚什么钱：f_high52 = 收/250日最高-1，low端=离高点最远（跌幅最大）。买“膝盖斩”后的修复。
- 什么行情赚：熊市深跌后反弹（2023H2-2024 TEST 63%、2025 OOS 43%）；什么行情亏：单边牛市中强者恒强时会被动拖（TRAIN 51%差8pp）。
- 与F1区别：F1看成交额，F3看位置；dd48w与high52高度相关（同族），本族只算1族。经济逻辑独立于流动性。

## 五零件
1. 选股：同池窄盘0.02~0.15，按high52取最低5只等权。
2. 买入：t信号t+1收盘。
3. 卖出：每60日轮换，无止损。
4. 仓位：统一MA15_0.2。
5. 止损：不设。

## 参数表
- 因子high52，方向low，N=5，R=60，size 0.02~0.15，cost 0.5%，择时MA15_0.2
- 复现：engine.py --factor high52 --direction low --n 5 --rebal 60 --size 0.02 0.15 --cost 0.005 --start 2023-07-01 --end 2024-12-31 --json --no-ledger（TEST裸15.8%/-46.8%），叠加后TEST 63.95%/-13.98%
