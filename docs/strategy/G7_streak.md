# G7 连涨跌（streak，中盘段）

> 一句话假设：过去5天连跌越多（streak越高=连跌减连涨越大取负后越高）的中盘小票，恐慌盘卖完后容易20~60天内修复。
> 否证线：IC持续为负且TEST回撤破-20%即放弃；OOS转负即降级为反例。
> 数据声明：新浪前复权长历史（pivots_2020_clean.pkl）。口径与F1~F5统一：单边0.5%，t+1，等权，现金0收益。

## 经济逻辑
- 赚什么钱：streak = -(近5天上涨天数-下跌天数)，越高代表近期连跌越重。赚“超跌修复+情绪均值回复”。
- 什么行情赚：震荡修复市（2021 +48.35%、2024 +72.48%、2025 +39.31%）；什么行情亏：单边熊初段（2020 -23.13%）。
- 与F2日内不同：F2看日内vs隔夜收益和（日内抛压），G7看过去5天涨跌天数count（情绪持续性）；同属量价大族但窗口与构造不同，故计为不同族。IC为负（-0.0312），组合收益靠小盘+择时，非纯信号alpha，如实披露。

## 五零件
1. 选股：上市>=250天、adv20>500万、流通市值5%~30%分位内取中段0.05~0.30（中盘段回撤更可控），按streak取最高3只等权。
2. 买入：t信号t+1收盘建仓。3. 卖出：每60交易日轮换，无个股止损。4. 仓位：中证1000<MA15→20%，否则100%。5. 止损：不设。

## 参数表
- streak-high N=3 R=60 size 0.05~0.30 cost单边0.5% MA15_0.2
- 复现：ASHARE_PIVOTS=pivots_2020_clean.pkl engine.returns_series('streak',high,N=3,Rb=60,sz=(0.05,0.30))+apply_index_filter

## 三关
- 时间顺切：TRAIN 14.64%/-33.11%/0.67（裸33.61%/-45.62%，IC -0.0312），TEST 52.74%/-19.12%/1.52（过40%/20%，压线），OOS 26.45%/-13.33%/1.16。TRAIN不过60%且回撤破线。
- 历年：2020 -23.13%/-28.94%、2021 +48.35%/-13.67%、2022 +23.39%/-14.13%、2023 +25.98%/-10.53%、2024 +72.48%/-19.12%、2025 +39.31%/-13.33%、2026 +12.15%/-13.03%。
- 敏感性（TEST中盘段Rb60）：N=3 52.74%/-19.12%、N=4 40.71%/-14.39%、N=5 42.37%/-14.89%、N=8 26.47%/-18.50%（N=3峰值但N4/5仍过，非单点孤峰，N8衰减）；Rb=20同N3仅36.3%/-21.2%（不达标），Rb60系统性优于Rb20。

## 多指数与成本分账（2026-11-25补）
- 择时变体（cost=0.005，TEST）：bare +10.52%/-57.25%（判死）；MA15_0.2_000852 +52.74%/-19.12%（基线唯一双过，压线）；MA20_0.5 +25.44%/-34.10%（破线）；MA60_0.5 +22.43%/-35.48%（破线）；MA15_0.2_000905 +46.85%/-27.66%（破线）。无过滤回撤-57%，仅MA15_0.2勉强压进线内，换指数或放宽cut即判死。
- 成本分账（TEST）：0.15%下+56.41% vs 0.5%下+52.74%，侵蚀3.67pp（bare下3.15pp）；R60低频不敏感，按0.5%结论不变。
