## 0. 一句话结论（设计意图）

**2026 的三条线互相打架，本批不堆网格，只花在「找出那个同时成立的角」上。**

| 想要 | 唯一可行的做法 | 代价 |
|---|---|---|
| 收益 ≥ 60% | 集中到 N ≤ 6（R30） | 段胜率掉到 3~4/6 |
| 段胜率 ≥ 80% | 分散到 N ≥ 8~10（R30 只有 6 段，5/6=83%） | 收益掉到 33~58% |
| 回撤 ≤ 15% | 止损 / 分散 / 行业中性 | 止损削收益；分散削收益；中性化腰斩收益 |

单旋钮无解 → 本批主攻 **N 8~12 + 松离场（none / trailing 10~15%）**，
以及（Lead 情报后） **`amihud_60` + 零售池（剔 688）** 这个已经被独立验证过的新前沿。

## 2. Lead 情报带来的三个设计修正（**很重要，读这段再读表**）

### 2.1 止损必须按「次日收盘」执行，same-close 是虚高来源
同一 spec（N5/R30/ts12）三口径：realistic 费用连续口径 **+62.8%**；0.5%/边成本 **+54.6%**；
2026 空仓起步 **+44.9%**；**止损改次日收盘执行 +56.5%**。
→ 本批所有 spec 按 `stop_exec = next_close`。预跑里「止损增收益」在 R15 上的结论要打折扣：
次日执行会系统性削掉止损伤收益的能力（同一档位约 -6pp）。
→ **对 addendum 的含义**：Lead 的 amihud_60 N5 是 +80.4%/**-14.1%**，回撤只剩 **0.9pp 余量**、收益有 20pp 余量。
所以止损在 addendum 里的定位是「买保险」而不是「提收益」，我给的档位是 8/10/12/15 四点 + N8/N10/N12 三条分散路径。

### 2.2 「全池达标」不可交易：2026 旧策略 35 个选股里 16 个是 688
**实测：本数据集没有北交所股票**（universe 里 0 只 8xx/4xx），所以 `exclude_bj` 是空操作；
**零售池的实质 = `exclude_star=true`（剔 688/689，606 只，占 12%）**。
→ `G13_retail_pool`（12 条）与 `A1` 的 retail/full 成对设计，差值就是「不可交易的收益」。
→ Lead 观察到「零售池在 amihud_60 上反而更好」——addendum 的 full 对照（7 条）专门验证这一点。

### 2.3 段胜率靠少数大赢家，`win_trade` 只有 50~56%
→ 新增 `G14_win_trade`（12 条）：固定止盈 20~30% + 止损 10~12% 的组合，专门打按笔胜率。
→ **代价必须明说**：固定止盈在 2026 已被证伪（砍大赢家），所以这一组不是来提高总收益的；
它要回答的是「能不能用 10~20pp 总收益换 10pp 按笔胜率」。若三线仍过，那就是口径最硬的达标解。

## 4. 结构性事实：胜率门槛随 R 剧烈变化

`PROTOCOL §3` 的主口径 `win_period` = **完整调仓段**净收益 > 0 的占比。2026 窗口 201 个交易日：

| R | 完整段数 n | 80% 需要 | 现实难度 |
|---|---|---|---|
| 30 | **6**（个别锚点 5） | **5/6**（83%）或 4/5（80%） | 段数最少 → 最容易过，但 1 段=16.7%，功效极低 |
| 15 | 12~13 | 10/12（83%） | 输 2 段就死；预跑最好 9/12=75% |
| 7 | 28 | 23/28（82%） | 结构上最难，费用吃掉 8~20% 本金 |

**这是 79 个 R30 / 20 个 R15 / 4 个 R7 的唯一理由**：不是偷懒，是段数数学。
**同时必须提醒 auditor**：R30 的 n=6，任何「5/6」都要配合 2025 同参数 OOS（PROTOCOL §5.5）才可信；
Lead 已经证明 **同一参数换锚点后 N5 从 5/6 掉到 3/6** —— 相位就是 R30 最大的假阳性来源。

## 7. 防过拟合约定（请 auditor 按这段审我）

1. **邻域优先**：每个 (N, 止损) 最多 3~4 点，且故意连成平台：
   止损 8 / 10 / 12 / 15；N 3-4-5-6（集中端）/ 8-10-12（分散端）；R 7 / 15 / 30。
2. **不做单点极值**：没有 0.11 / 0.13 这种「只此一档」的参数。
3. **对照组齐全**：同一行里同时有 none 与止损、tracking 与 fixed、止盈与不止盈、amihud 与复合因子、retail 与 full。差值才是证据。
4. **预注册预期**：每组都写了预期。若结果与预期相反（例如 low_vol 反而 +60%），
   必须在 review 里标 `异常，需独立复核`，不能直接当发现。
5. **尝试次数要记账**：001 主体 107 + addendum 39 + phase 6 + 002 89 = **241 次尝试**（其中 6 条是重复锚点）。
   这是数据窥探的分母，auditor 的 bootstrap / 邻域检验必须用这个数。
6. **addendum 是「定向确认」不是「独立搜索」**：它的参数来自 Lead 的独立实现，
   因此**不能**用来主张「我们在 241 次里只挑出最好的那个」——反而应该问：
   同一批参数换锚点/换池后还成立吗（phase_probe + full 对照就是为此准备的）。
