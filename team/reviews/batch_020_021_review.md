## 2. n 红旗: W5/V6 的 N2/N6 只存在于 id 里 (spec 恒等, 非引擎 bug)

- `W2 vs W5`: 除 `id`/`notes` 外**逐字段一致** (spec md5 均为 `fa444372…`), 交易序列 200/200 全同, 首仓 (000692/002005/002700/603559, 2024-01-03 建仓) 逐笔一致。**W5 的 n=4, 所谓 "N2" 只存在于 id 字符串。**
- `W2 vs V6`: 同上, md5 同为 `fa444372…`, 交易 200/200 全同。**V6 的 n 同样 =4, "N6" 亦只存在于 id。**
- 定性: **strategist/spec 生成 bug (N 从未被真正改动), 不是 harness 引擎 bug, 更不是独立复现。** W5、V6 必须从一切 “R7 超越 R30” 的证据计数中剔除 —— 所谓“三处一致”实为**同一条策略被数了三遍**。建议: 今后 batch 一律跑 `spec_identity` 去重门禁 (本审计脚本已含该检查)。

辅助口径 (全部指向同一结论):
- 月胜率 2025: W1 / W2 / V1 / V2 / V3 / V6 **全部 8/11**, 无任何区分度 (月度曲线几乎重合: 3 月 +14~16%、9 月 +30.6~30.9%)。
- 调仓段胜率: W1 **100% (7/7)** vs R7 系全部 **67.6% (23/34)** —— R7 用段胜率换总收益, 且段样本功效远低于 W1。
- 按笔胜率: W1 68.75%/32 笔 vs W2/V1/V2 57.3%/96 笔 (V3 59.0%/100 笔) —— 按笔显著更差。
- mdd: W2 −12.74% vs W1 −10.07% (差 −2.67pp, 在容忍线 −13.07% 内但方向为劣); V1/V2/V3 −12.6~−12.7% 同理。

→ +2.2pp 的点估计落在 ±30pp 的 CI 正中; V2 的 +14.9pp 看似大, 但其 CI (−23.5%, +41.2%) 同样横跨零点且 P(>0) 仅 58%。**按 Lead 规则 (差距不显著即 WEAK): 020 与 021 全部判 WEAK, 无一可申报突破。**

- 挑战方在 4/4 phase 上全部战胜同 phase W1 —— 方向一致性是真实信号 (非 phase 运气, phase0 恰是各方最弱档之一)。
- 但 magnitude 方差极大 (W2 超额 +2.2~+21.1pp, 10 倍极差) —— 与 bootstrap 的 fat-tail CI 自洽: 少数重仓段/重仓日决定全年, 相位一变差距就变 10 倍。**这正是“不能申报突破”的理由**: 同样的机制既能给出 +2pp 也能给出 +21pp, 点估计不可信。
- V2 在 4 档全部领先且幅度最大 (+8~+21pp), 是唯一值得**后续立项**(更大样本/OOS 验证)的候选, 但本次仍判 WEAK (P=58%)。

**最终判定**:
- **020 (W2 vs W1 +2.22pp) → WEAK**: 数字复现无误, 但 spread P(>0)=46.5%、月胜率无区分 (8/11 打平)、段胜率/按笔胜率/mdd 全劣; W5 系重复计数, 剔除。
- **021 V1/V2/V3 → 全部 WEAK** (+11.2/+14.9/+8.2pp, P=55/58/52%, CI 全跨零; 相位 4/4 胜但极差 10 倍); **V6 → 剔除** (W2 第三副本)。
- **n 红旗定性**: strategist/spec 生成 bug —— W5/V6 的 N2/N6 仅存在于 id 字符串, 实际 selector.n 全为 4, 三者为同一策略的三次重复运行; 非引擎 bug, 但同等严重 (虚增了“多处一致”的证据感)。
